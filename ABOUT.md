# About Modescope

This is why I built Modescope and what I want it to do. The [guide](GUIDE.md) explains how to use it.

## How it started

### The modes are one ring

It started while I was reading [The Ultimate Scale Book](https://www.amazon.com/dp/0793597889) by Troy Stetina. Appendix A lists every mode with its tones and its structure, meaning its pattern of whole and half steps. I noticed that Dorian has the same structure as Ionian if you picture the pattern as a ring and shift it one place to the left. Every mode works the same way. They aren't seven separate scales but one pattern of steps, started from a different place.

### Borrowed chords

The second idea came from Rick Beato's video [What Makes This Song Great? "Smells Like Teen Spirit" Nirvana](https://www.youtube.com/watch?v=l1ZnWc-sFd0). Rick talks about how Kurt Cobain used a lot of "borrowed" chords to make interesting melodies. Borrowed chords are usually described as coming from a different key. I wondered if a borrowed chord could instead be thought of as coming from a different mode on the same tonic.

It turns out this is an established idea in music theory, called **modal interchange** or **modal mixture**. I wanted a way to see it, and that's how Modescope came about.

## Goals

1. **Show the modes as one ring.** Turning the wheel should make it obvious that each mode is the same pattern of steps, shifted. Moving from C Ionian to D Dorian keeps the notes and moves the tonic (relative modes).
2. **Make modal interchange visible.** Keep the tonic fixed and compare its modes (parallel modes). For any note, I want to see which chords on it belong to which mode, so a "borrowed" chord can be traced back to the mode it comes from.
3. **Explain the theory along the way.** Chord spellings, scale degrees and Roman numerals should explain themselves, so I can learn the vocabulary while I use the app.

These goals take priority over adding more features. A change should make one of these ideas easier to see or understand.
